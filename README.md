# Teromox
개인 서버(On-Promise)로 AWS, GCP와 같은 VPS 가상 머신을 제공하는 서비스  
https://github.com/Teromox

## 기술 스택
- Fastapi
- Proxmox
- Ubuntu
- Cloud-init
- iptables
- SpringBoot
- React
